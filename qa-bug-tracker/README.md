# QA Bug Tracker Dashboard

A complete bug-tracking tool for manual QA work: report defects with
severity and steps to reproduce, triage by filter and search, track
fix rate, and export the report as JSON or CSV for a client or team.

## Stack
HTML · CSS · JavaScript (no build step, no framework) · localStorage

## Run it
Just open `index.html` in a browser. No server, no install.

## Features
- **Full bug lifecycle:** report → open → fixed → reopen, plus delete
- **Real QA fields:** severity (Critical/Major/Minor/Trivial), module,
  steps to reproduce, expected vs actual result
- **Triage tools:** live search, severity filter, status filter
- **Stats:** total bugs, open count, critical-open count, fix rate
- **Exportable reports:** one-click JSON and CSV export — the format a
  QA tester actually hands to a developer or client

## Why this matters
- **Directly matches your QA experience** (Mindrift, Decode Labs):
  this is the tool version of the job you already did.
- **Shows product thinking:** a complete workflow, not a demo snippet.
- **Client-ready:** a freelancer can use this on a real website QA gig
  and deliver the exported report as the deliverable.
