## 🎯 What these prove

- **Backend engineering** — REST API design, request validation, SQL
  aggregation, indexed queries (telemetry-logger)
- **Applied security** — key derivation, symmetric encryption, secure
  CLI design, threat modelling (secure-vault)
- **Product thinking** — a complete user workflow from report to
  exportable deliverable, not a snippet (qa-bug-tracker)

## 🧪 Quality

All three were tested end-to-end before delivery: API endpoints
(including invalid-input rejection), encryption round-trips
(including wrong-password rejection), and JavaScript syntax checks
all pass. Each project README documents how to run and verify it.
